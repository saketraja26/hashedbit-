# HashedBit Assignments

This repository contains all my assignments completed for the HashedBit Innovation program.

## 📚 Assignments Overview

### Assignment 1 - Webpage Design
A responsive webpage with header, navigation, sidebar, and content sections using HTML and CSS.

### Assignment 2 - JavaScript Basics
JavaScript fundamentals covering variables, functions, and basic operations.

### Assignment 3 - JavaScript Practice
Advanced JavaScript exercises focusing on arrays, objects, and ES6 features.

### Assignment 4 - DOM Manipulation
Four mini-projects demonstrating DOM manipulation:
- Dark Theme Toggle
- Dynamic Div Creation
- Dynamic CSS Styling
- Hide/Show Paragraph

### Assignment 5 - React Calculator
A functional calculator built with React, supporting basic arithmetic operations.

### Assignment 6 - React Todo App
A todo list application with add and delete functionality, built using React.

### Assignment 7 - IPL Points Table
An interactive IPL points table displaying team statistics using React.

### Assignment 8 - Movie Booking System
A complete movie booking application with movie selection, seat booking, and confirmation.

### Assignment 9 - JavaScript Practice (Delta)
Comprehensive JavaScript practice covering variables, arrays, objects, and array methods.
